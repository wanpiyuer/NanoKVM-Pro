更新、备份与回退（2026-10-15）

一、更新会影响哪些部分
普通重启：持久安装的候选内核、运行时脚本和网页联动会保留。
应用升级：可能替换网页和 USB 启动脚本，网页按钮联动可能失效。
底层固件/内核升级：可能覆盖候选内核，使 p_jack_detect/p_jack_connected 能力消失。
整机重刷：需要重新核对基线并安装定制功能。
本包不会阻止官方升级，也没有升级后自动修复机制。
升级前先取得目标版本对应的适配包；升级后不要直接重跑本包或跳过版本/哈希检查。

二、每台备份分别保管
Prepare 读取和保存的是当前这台新机的原始分区与必要配置，并下载到 Windows。
本地目录为本包 backups\<KVM的IPv4地址>\，保留其中的 .tar.gz、receipt.json 和 state.json。
设备绑定采用 eMMC CID 的 SHA-256；不要手改状态文件，也不要把别台备份复制进来冒充本机备份。
保留终端打印的路径、校验文件和报告，建议把整个本地备份目录再复制到另一存储位置。
备份属于该设备，不要发到公开网盘；其中配置可能含设备身份或私有信息。
它是本安装方案需要的分区/配置备份，不是整机镜像，不能恢复误擦的其他分区或文件。
不可用旧机备份、旧机恢复 AXP 或别台 KVM 的序列号/配置替代。

三、查看状态
双击 Start.cmd，在中文安装窗口填写目标 KVM 的当前 IP，点击“查看状态”（Status）。
任务窗口会自动打开，只按提示输入 root 密码，无需手动打开终端或输入命令。
状态检查不会刷写内核、重启 USB 或安装网页。
若报告文件被覆盖、版本不匹配或事务未完成，保留输出，先诊断。

四、回退网页联动
1. 关闭所有 KVM 网页标签。
2. 双击 Start.cmd，在中文安装窗口填写目标 IP，点击“回退网页”（RollbackWeb）。
   按自动打开的任务窗口提示输入 root 密码。
3. 成功后重新打开网页并按 Ctrl+F5，确认回到原网页入口。
这只恢复原网页入口并停止、移除新增租约服务和包装脚本。
它保留候选内核、jack 运行时及备份；新增的版本化网页资源也保留，避免旧标签懒加载失败。
回退后原网页按钮不再控制 jack；如需其他后续操作，由维护人员安排，不要求用户自行输入终端命令。
若当前文件后来被其他程序修改，回退会拒绝覆盖，不应强删备份或强制重试。

五、回退运行时或内核
本简化安装窗口不提供一键内核恢复、整机恢复或批量自动刷写。
若必须恢复原内核，应先核对本台 Prepare 备份和目标分区，再为本台制作恢复 AXP。
原始 kernel/kernel_b/dtb/dtb_b 等备份不能直接拖入候选包当恢复方案。
不要用官方 update_kernel.sh：它可能同时更新两个 kernel 槽，与本次单槽方案不同。
若不能启动，使用现场可操作的 User/Reset 与 AXDL 安排恢复；不要盲目擦除或重分区。

六、安装失败后的原则
保留本地备份、KVM 上安装器打印的持久 setup 路径和状态目录。
不自动重试 activate，不自动回滚；先检查失败发生在哪一阶段。
首次运行时激活会重建一次 USB，因此通过网线/Wi-Fi SSH 操作。
网页安装/回退不会主动重启原 NanoKVM 服务或 USB。
没有出现成功状态时，不把“上传 100%”当作安装完成。

七、验收边界
当前已有一台 Pro 真机完成：候选内核启动、手动和网页开关、默认录音切走/返回、复开有声。
新中文安装窗口和自动编排在离线 fixture 中检查；每台新硬件仍须按“00-开始.txt”的步骤 4 完成验收。
Windows 默认设备策略、应用自行固定输入、后台页面节流、网络质量会影响实际使用。
关闭失联租约通常约 10 秒；正常点击开关与失联兜底不是同一种响应时间。
尚无所有 Windows 版本、全部应用或量化开关延迟的通用保证。
