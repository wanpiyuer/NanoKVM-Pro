NanoKVM Pro 网页麦克风：新机安装包（2026-10-15）

这套包把网页麦克风按钮与 Windows 中的麦克风可用状态联动。
开启后接通并传声，关闭后 Windows 可切回其他录音设备；日常开关不重启 USB。
在已测试的 Windows 电脑上，先把该麦克风设为默认一次，之后关/开会自动切走/选回。
安装保留新机当前的 USB 名称、VID/PID、序列号等身份配置，不自动改成 Logitech。
如需自定义 USB 名称，先在设备上完成改名并正常重启，使名称生效，再点“① 检查并备份”。
本包不负责自动改名；原厂新机不需要做这一步。

适用范围
只适用于本包检查通过的 NanoKVM Pro eMMC 基线：应用 1.2.15、原厂内核
4.19.125 及固定文件/分区哈希。版本号相同也要通过检查。
不是 NanoKVM Cube、NanoKVM Go、PiKVM 或任意新版本的通用安装包。
已在一台 Pro 上验证内核启动、网页开关、Windows 默认输入切换和重新开启后有声；
其他 Windows 版本、各录音软件及精确延迟仍需在对应机器验收。

要准备什么
1. 一台 Windows 电脑：运行本包、AXDL 与 SSH；可以是任意电脑，不一定是被控电脑。
2. 新 KVM：用网线或 Wi-Fi 与这台电脑联网，知道 KVM 的当前 IP 和 root SSH 密码。
   不要依赖 KVM 的 USB 虚拟网卡完成安装，首次激活会重建一次 USB。
3. 一根能传数据的 USB 线，可现场操作 KVM 的 User/USR 和 Reset 按钮。
4. 在 KVM 网页“设置 → 设备”中打开 SSH。若改过网页账号密码，SSH 密码也可能同步改变。
5. Windows 本地和 KVM 的 /root 均需有足够空间存放本台备份，建议至少各留 500 MiB。

步骤 0：完整解压
把整个 ZIP 解压到 Windows 的本地目录，例如 C:\NanoKVM-Mic。
不要在压缩包中直接运行，不要只复制一个 ps1 文件，也不要把文件放进 KVM。
进入解压后的文件夹，双击 Start.cmd，打开中文安装窗口，在输入框填写新 KVM 的 IP。
不需要自己打开 PowerShell 或 KVM 终端，不需要复制、粘贴任何命令。
点击操作按钮后会自动弹出任务窗口；按提示输入 root 密码即可，可能要求多次输入。
输入密码时不显示字符，密码不会保存到脚本。
任务结束后，保留最终结果，按 Enter 关闭任务窗口；安装窗口会恢复按钮供下一步使用。
首次 SSH 连接会显示主机指纹。确认 IP 是这台 KVM 后再接受；不要把“KVM_IP”当成真实地址。

步骤 1：准备和备份
点击“① 检查并备份”（日志动作名 Prepare）。
它读取并检查新机基线，备份这台新机的原始分区与必要配置，再下载到当前 Windows。
这是备份步骤，不刷写分区、不安装麦克风功能，也不重启 USB。
只有任务窗口明确报告 PREPARE COMPLETE，且本地备份下载/校验成功，才进入下一步。
本地备份位于本包 backups\<KVM的IPv4地址>\ 中：
originals-<归档SHA256前12位>.tar.gz 是原始备份，receipt.json 是校验回执，state.json 是设备绑定记录。
设备通过 eMMC CID 的 SHA-256 绑定，不依赖可能重复的 USB 序列号；原始 CID 不输出到终端。
每一台 KVM 都必须单独 Prepare，不能复用别台备份，不要手改回执或绑定记录。

步骤 2：只刷一个 KERNEL
关闭所有 KVM 网页标签，先点击“安装 AXERA 驱动”，再点击“② 打开 AXDL”。
驱动按钮自动安装包内 AXERA 驱动；若 Windows 询问管理员授权，按提示允许。
无需查找 DriverSetup.exe 或手动输入驱动命令，等待安装窗口报告驱动处理完成即可。
按钮会打开工具、候选包所在文件夹及操作说明；按“AXDL-操作.txt”核对和刷写。
AXDL 的镜像选择、选项核对、开始烧写以及 KVM 的实体按键仍需现场操作。
这里只刷包内 candidate\REVIEW-candidate-kernel-A.axp，不选整机官方镜像。
看到 KERNEL / Finish / Passed 后先停止 AXDL，再让 KVM 完全断电后正常开机。
“完全断电”包括断开可能给 KVM 供电的 HID USB；重新上电时不要按 User/USR。
等 KVM 重新联网。IP 若变化，后面填新地址。

步骤 3：统一安装
回到中文安装窗口，在 IP 输入框填同一台 KVM 的当前地址，点击“③ 刷写后自动安装”
（日志动作名 InstallAfterFlash）。保持所有 KVM 网页标签关闭，按自动弹出的任务窗口提示输入密码。
IP 若变化，程序会查找此前的备份；只有一份时自动选用，多份时在任务窗口按编号选择。
备份所绑定的设备必须与当前 KVM 相同，不匹配会停止。
这一步自动检查候选内核、安装并激活运行时、初始化缺少的脚本目录、安装网页联动。
首次激活只重建一次 USB，键鼠和 USB 网卡会短暂断开；之后网页日常开关不重建 USB。
安装成功后麦克风初始为关闭状态。保存终端最后输出，不要在报错后连续重试。

步骤 4：验收
1. 把 KVM 的 HID USB 接到要使用虚拟麦克风的 Windows 被控电脑。
2. 打开控制端 KVM 网页，按 Ctrl+F5 刷新，选择 H.264 WebRTC 或 H.265 WebRTC。
3. 麦克风按钮提示应包含 Mic bridge 20261015。
4. 点击开启并允许浏览器采集，在被控 Windows 确认录音有声音。
5. 首次在 Windows 中把此虚拟麦克风设为默认录音设备；若使用通信软件，检查其输入选择。
6. 做一次“开 → 关 → 开”：关闭后切回其他麦克风，再开启选回且仍有声音。
7. 同时确认 KVM 键鼠正常，USB 名称仍是安装前的名称。

之后怎么用
以后直接点击 KVM 网页麦克风按钮。正常关闭立即停采集并请求断开麦克风端子。
断网、网页崩溃或后台计时器严重节流时，租约约 10 秒后会关闭端子；恢复连接需再次手动开启。
同一时间只允许一个网页窗口占用麦克风。

状态和回退
点击“查看状态”（日志动作名 Status）：查看当前状态，不安装或刷写。
点击“回退网页”（日志动作名 RollbackWeb）：回退网页联动，保留候选内核和 jack 运行时。
点击“打开说明”：打开本包操作说明。
点击“打开备份文件夹”：打开本包 backups 目录。
完整说明见“更新与回退.txt”。本包没有一键恢复整机或内核功能。
不要用旧机器的 restore AXP 恢复新机器；本包不包含旧机器的恢复镜像、分区备份或设备密钥。

遇到错误
Connection refused：到 KVM 网页设置打开 SSH，确认 IP。
Permission denied：核对 KVM 的 root SSH 密码；不是 Windows 登录密码。
baseline/hash/version mismatch：不匹配本包，停止；不要关闭检查来继续。
MIC_NOT_MOUNTED：先在原 KVM 网页启用虚拟麦克风设备，再关闭网页采集和全部标签，重按“① 检查并备份”。
PENDING_USB_IDENTITY：持久 USB 配置与当前生效的身份不一致。正常重启 KVM 后，再试刚才的操作；无需输入终端命令。
backup/transaction incomplete：保留本地备份、日志和终端输出，先诊断再决定后续动作。
不能正常开机：停止继续刷写，保留该台 Prepare 备份，按“更新与回退.txt”安排恢复。
